# Guia-SCDP-Diarias-e-passagens
É sobre o uso do Sistema de Concessão de Diárias e Passagens (SCDP), focando no perfil do solicitante de viagem que é o responsável por inserir dados fundamentais, como trajeto, motivo do afastamento e identificação do beneficiário. Além de orientar sobre alteração de viagens, aborda regras para situações especiais, como a prestação de contas.
